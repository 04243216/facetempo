# FaceTempo 技术报告

**面部位移与表情节奏的量化诊断：以眼周微颤区分真人与 AI 生成人脸**

版本：W4.4 ｜ 日期：2026-11-13 ｜ 代码仓库：`E:\FACETEMPO`

---

## 摘要

AI 生成的人脸在静态画质上已接近真人，但在时间维度上往往缺乏真人肌肉控制固有的微小不自主抖动。本项目构建了一条从视频到可解释指标的处理管线：基于 MediaPipe FaceLandmarker 同时提取 478 个面部关键点与 52 个 Blendshape 系数，经眨眼屏蔽、统一帧率重采样后，计算**归一化眼周 Jerk**（单位幅度下的高频加速度能量）。在 4 条真人自然微笑与 4 条 AI 生成正脸视频的主队列上，真人组中位数为 77.29，AI 组为 35.63，两组完全无重叠，精确单侧置换检验 **p = 0.0143**（4v4 的数学下限）。在 2 条真人 + 2 条 AI 的独立盲测集上，方向完全复现且两个指标均无重叠（真人 40.51 / 96.20，AI 26.65 / 18.31），但 2v2 的 p 值下限为 0.1667，只能作为方向性支持。真人假笑组中位数为 59.62，介于真人与 AI 之间。

---

## 1. 研究背景与问题

生成式视频模型能够合成高质量的人脸外观，却难以复现神经肌肉控制中的微尺度时间结构。真人的面部在保持表情时仍存在持续的微小抽动与高频调整；AI 生成结果则倾向于过度平滑、帧间高度一致。这种差异在单帧上看不见，但在逐帧序列的二阶差分中会形成稳定的能量差。

本项目回答两个问题：

1. 能否用消费级摄像头与开源模型，量化“眼周微颤”这一时间特征？
2. 该特征能否在同一采集协议下区分真人自然表情与 AI 生成表情，并在独立样本上复现？

## 3. 方法

### 3.1 双通道特征提取

使用 MediaPipe Tasks API 的 `FaceLandmarker`（VIDEO 模式，478 个归一化关键点），单次解码同时输出：

- **几何通道**：EAR（眼睑开合）、MAR（嘴部开合）、眉高、`smile_lift`（内眼角中点与嘴角中点的垂直距离 / 脸宽）、`mouth_width`（嘴角水平拉伸 / 脸宽）、几何眼开合 `eye_aspect_ratio_geo`、人脸框中心与尺寸。
- **肌肉通道**：52 个 Blendshape 系数（51 个动作通道 + `neutral`），并对每列做 3 帧居中中值平滑，生成 `_smooth` 列。

几何特征在像素坐标下计算后再除以像素脸宽，避免 16:9 归一化坐标的各向异性拉伸。

### 3.2 数据质量门控

| 门控 | 阈值 | 目的 |
|---|---|---|
| 人脸覆盖率 | ≥ 95% | 排除丢脸、遮挡、镜头跳变 |
| 头部运动速度 | < 0.5 脸宽/秒 | 排除大幅甩头 |
| 头部最大偏移 | < 1.5 脸宽 | 排除镜头级位移；允许慢漂移 |
| 眼通道一致性 | 两通道 std ≥ 0.008 时，相关必须 < 0 | 检测关键点/通道失配；低方差记 N/A |
| 嘴部动态 | 仅记录，不做硬门控 | 避免误杀幅度小的假笑 |

门控只决定样本是否进入统计，不修改原始数据；被拒样本的原因全部保留在报告中。

### 3.3 眨眼屏蔽

`eyeSquint` 的高频能量主要来自眨眼，而非微颤。计算眼周 Jerk 前，将 `eyeBlinkLeft/Right_smooth > 0.5` 的帧及其前后各 2 帧排除。该步骤将 AI 组的伪高频压回真实水平，是区分度成立的关键。

### 3.4 统一帧率与归一化 Jerk

不同来源帧率为 24 / 25 / **59.9** fps。逐帧二阶差分对采样率极其敏感，若直接比较会产生系统性偏差。所有信号先线性重采样到 **25 fps**，再计算：

```
speed = mean(|x[t+1] - x[t]|) × fps
jerk  = mean(|x[t+2] - 2x[t+1] + x[t]|) × fps²
normalized_jerk = jerk / std(x)
```

归一化消除了动作幅度的影响；统一帧率消除了采样率的影响。眼周与嘴部分别计算，主指标为**眼周归一化 Jerk**，眼周 5–12 Hz 高频能量为次要指标。

### 3.5 统计检验

组间比较采用**单侧置换检验**（H₁：真人 > AI）。组合数 ≤ 200,000 时精确枚举全部标签排列，否则蒙特卡洛近似。4v4 的精确 p 下限为 1/C(8,4) = 0.0143；3v4 为 0.0286；2v2 为 0.1667。

## 4. 实验结果

### 4.1 主队列（4 vs 4）

| 组 | 归一化眼周 Jerk（各条） | 中位数 |
|---|---|---|
| 真人 | 105.70 / 67.59 / 86.99 / 67.03 | **77.29** |
| AI | 27.02 / 21.63 / 44.25 / 55.03 | **35.63** |
| 假笑 | 65.89 / 55.49 / 63.75 / 41.34 | 59.62 |

- 真人最小值 67.03 > AI 最大值 55.03，**两组完全无重叠**；
- 精确单侧置换检验 **p = 0.0143**（4v4 下限）；
- 眼周高频能量：真人 0.014–0.063，AI 0.007–0.032，p = 0.0429。

### 4.2 独立盲测（2 vs 2）

| 组 | 归一化眼周 Jerk | 高频能量 |
|---|---|---|
| 真人 | 40.51 / 96.20 | 0.016 / 0.073 |
| AI | 26.65 / 18.31 | 0.007 / 0.006 |

两个指标均无重叠，方向与主队列一致。p = 0.1667 = 1/C(4,2)，为 2v2 的数学下限，**不能作为显著性证据**，只能说明排序完全复现。

### 4.3 假笑组

中位数 59.62，位于真人自然笑（77.29）与 AI（35.63）之间；4 条中 3 条高于 AI 最大值（55.03）。这与“假笑缺乏眼周微动态、但仍有真人肌肉底噪”的预期一致，样本量不足以单独下结论。

### 4.4 联动分析（次要）

全片嘴部/眼周相关性与滞后在多数样本上偏弱，且最佳滞后频繁触及 ±1 s 搜索边界；事件级 Bootstrap 在部分强事件上 r 可达 0.9 以上，但事件间方向不一致。**联动指标目前不具备组间判别力，未作为主结论依据。**

---

## 5. 讨论

1. **指标有效性**：归一化眼周 Jerk 衡量单位幅度下的高频加速度能量，对应“微颤/不自主抖动”，与画质、分辨率无直接关系；重采样与眨眼屏蔽确保它不被采样率和瞬态污染。
2. **判别边界**：主队列与盲测均无重叠，说明差异不是单队列过拟合；但样本量小，效应量尚未在更大规模上验证。
3. **假笑的中间位置**：提示该指标捕捉的是“时间维度的自然度”，而非简单的“是否在笑”；假笑仍是真人肌肉，但眼周动态弱于自然笑。
4. **工程可复现性**：质量门控、重采样、眨眼屏蔽、精确置换检验全部固化在 `src/plot_dynamics.py`，任意新样本可用两条命令重跑。

---

## 6. 局限

- 主队列每组 4 条、盲测每组 2 条，样本量小；主队列 p 值已触到 4v4 下限。
- 真人与 AI 素材的分辨率、压缩、内容不完全一致，存在画质混杂可能。
- 微颤指标依赖 25 fps 重采样，原始 60 fps 素材的高频信息被有意截断以匹配其他样本。
- 眨眼阈值 0.5 与膨胀 2 帧为预设值；敏感性扫描 9 组中 8 组 p < 0.05。
- 结论仅适用于本批受控样本，不能直接外推到所有生成工具或人群。
