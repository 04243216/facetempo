## 通用约定

| 项目 | 约定 |
|---|---|
| 时间基准 | 统一用秒（`timestamp_sec`），不用帧号做跨来源比较 |
| 坐标归一化 | 关键点先按双眼间距或脸宽归一化，再算位移 |
| 强噪声 | 取指标前先剔除 `face_found == 0` 的帧与低置信度帧 |
| 平滑 | 报告里注明是否做平滑（窗口长度、滤波类型），因为平滑会抹掉部分节奏信息 |
| 版本 | 指标口径变更时，在 `diagnoses.model_version` 里带版本号 |
| 缺失值 | 指标不可计算时写 `null`，并在报告中说明原因，不要填 0 |
