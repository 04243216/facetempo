## 拍摄条件记录模板

新增视频时在下方追加一条，便于后续做条件对照：

```
文件名：
日期 / 设备 / 分辨率 / 帧率：
工具与版本（AI 片段）：
提示词或驱动输入（AI 片段）：
光照 / 距离 / 头部姿态：
授权状态：
```
